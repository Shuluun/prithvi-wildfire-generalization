# terratorch version decision:
#   The official requirements.txt pins terratorch @ git commit ca289f06 (== PyPI 0.99.5,
#   2024-11-26). That commit PREDATES the registration of `prithvi_eo_v2_300`
#   (added 2024-11-27/28 in terratorch/models/backbones/prithvi_mae.py) — the official pin
#   is internally inconsistent with the repo's own firescars.yaml / the HF BurnScars model.
#   We therefore use PyPI terratorch==0.99.7 (2024-12-06, BurnScars release era):
#   it registers prithvi_eo_v2_300 and satisfies torch<=2.5.0, lightning 2.x (!=2.3),
#   torchgeo>=0.6.0, torchmetrics<=1.3.1 — compatible with the official 2024-11 pin stack.
#   terratorch 0.99.8+ would force torch 2.6 / lightning 2.5 (rejected).
# Removed from the official list:
#   - triton==3.1.0                   -> Linux-only, not in Windows torch wheels
#   - bitsandbytes==0.44.1            -> no Windows support (0.50.x installed transitively)
#   - PrithviWxC / granitewxc         -> unrelated model repos
#   - dev tools (ipython, ipdb, ...)  -> not needed
# Added for this project: seaborn, pytest.
